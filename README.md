# Landing page para un artista

## Descripción

Este proyecto consiste en crear una primera versión de un sitio web para un amigo artista que necesita darse a conocer y exponer su talento. Será una landing page de una sola página, desarrollada con HTML y CSS.

## Misión

Presentar el trabajo escultórico de Fred Flinstone y ofrecer un espacio digital donde las personas puedan conocer sus piezas, su trayectoria y sus próximas presentaciones.

## Visión

Construir una presencia digital que pueda crecer junto con la obra del artista y convertirse en un punto de referencia para conocer su trabajo.

## Objetivo

Crear una landing page accesible y fácil de recorrer que dé la bienvenida a los visitantes y presente las esculturas de cemento, la trayectoria y las próximas presentaciones del artista.

## Público destinatario propuesto

El briefing no define un perfil demográfico concreto. Como hipótesis inicial, la página se dirige a personas interesadas en la escultura y los objetos decorativos, así como a organizadores y espacios culturales que quieran conocer el trabajo o las presentaciones del artista. Este público deberá validarse con el artista.

## Estructura de la página

La landing tendrá una barra de navegación con enlaces a las secciones principales:

- Bienvenida o portada.
- Sobre mí.
- Trayectoria.
- Próximas presentaciones.

Cada sección ocupará aproximadamente el alto de una pantalla de computador.

## Accesibilidad

Se utilizarán etiquetas de accesibilidad para facilitar la navegación a personas con diversidad funcional visual y a usuarios de lectores de pantalla.

## SEO y datos estructurados

Se aplicarán principios de SEO para facilitar que la página pueda encontrarse en buscadores. Se utilizarán HTML semántico y marcado Schema.org.

## Tecnologías

- HTML
- CSS

## Dirección visual propuesta

La identidad visual debe destacar la materialidad, las texturas y las formas de las esculturas sin confundir el trabajo artístico con la construcción.

### Paleta de colores

- **Gris cemento:** color principal para evocar el material de las piezas.
- **Blanco cálido:** fondo neutro para dar protagonismo a las obras.
- **Terracota o arcilla:** color de acento inspirado en los tonos minerales.
- **Carbón:** texto y elementos de alto contraste.

Estos colores son una propuesta para la maqueta, no una identidad confirmada por el artista.

### Imágenes e iconografía

- Priorizar fotografías de las esculturas reales, con encuadres que permitan apreciar su forma y textura.
- Usar recursos gráficos inspirados en moldes, volúmenes y superficies minerales.
- Evitar iconografía de herramientas o construcción, para mantener el foco en la práctica escultórica.
- Escribir textos alternativos que describan cada imagen concreta; no reutilizar el texto de ejemplo como descripción genérica.
